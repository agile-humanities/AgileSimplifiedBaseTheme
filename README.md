# Simplified Agile Base Theme

A drop-in Omeka S theme by Agile Humanities Agency. It works with any Omeka S configuration, needs no modules
and no build step, and is configured through ordinary theme settings and CSS variables.

**Status: placeholder.** The theme is not built yet. For now this folder contains only `config/theme.ini`, so
selecting it in Omeka gives the core default appearance.

## How this theme is produced

This theme is **generated** from the Advanced Agile Base Theme
([AgileBaseOmekaTheme](https://github.com/agile-humanities/AgileBaseOmekaTheme)). Its stylesheet and templates
are output by a script in that repository and should not be edited here by hand; changes belong in the
Advanced theme's sources.

## Versions

The Simplified and Advanced themes carry the same version number, aligned with Agile Theme Tools 2.x.
